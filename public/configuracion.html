1. Crear las tablas y proteger las fotos

  1. En Supabase, abre este proyecto y entra a SQL Editor → New query.
  2. Escribe el correo que autorizarás en el formulario de abajo, pulsa el botón para copiar, pega el script completo en la consulta y pulsa Run. El script crea las tablas, permisos, funciones y almacenamiento privado. No sobrescribe cambios existentes si lo repites.
  3. Espera el resultado correcto antes de continuar. Si falla, comparte únicamente el mensaje del error.

Si el panel ya funciona, no necesitas repetir esta instalación. La autorización existente se conserva.

2. Autorizar el retorno a tu web

En Authentication → URL Configuration:

Site URL:

https://loscogolloshermanos.github.io/-los-cogollos-hermanos./

Añade esta dirección exacta a Redirect URLs y guarda: 

https://loscogolloshermanos.github.io/-los-cogollos-hermanos./?admin=1

Para desarrollo local, opcionalmente añade http://localhost:5173/?admin=1. Conserva la plantilla predeterminada de Magic Link que utiliza {{ .ConfirmationURL }}.

3. Crear tu usuario administrador

  1. En Authentication → Users, comprueba si existe tu correo administrador. Tu cuenta de la plataforma Supabase y el usuario de esta web son cosas distintas.
  2. Si no existe, usa Add user → Invite user para invitar ese correo. Abre el correo y acepta la invitación para verificarlo. Si solicita una URL de retorno, usa la dirección del paso anterior.
  3. En Authentication → Providers / Sign In → Email, mantén Email activado. Desactiva Allow new users to sign up y el acceso anónimo. No necesitas habilitar confirmaciones por teléfono ni contraseñas para el panel.

El correo debe quedar confirmado. Aunque otra cuenta consiguiera una sesión, los permisos del servidor le impiden editar datos, leer borradores o subir fotografías.

4. Comprobar el acceso por correo

Abre tu panel y pulsa Enviar enlace de acceso. Abre el enlace del correo y revisa también spam. Puedes abrirlo en otro navegador: el acceso usa el enlace, sin depender de una contraseña ni del navegador que lo solicitó.

Supabase limita los envíos y su correo predeterminado puede restringir destinatarios a miembros del proyecto. Si indica Email address not authorized, verifica que el correo administrador sea miembro de la organización o configura tu propio SMTP en Authentication para un uso continuo. No envíes credenciales SMTP por el chat. Si aparece rate limit, espera al intervalo indicado en Supabase.

5. Administrar y publicar

  • Productos: crea, edita, ordena o elimina. «Incluir al publicar» controla si aparece en el catálogo.
  • Fotografías: sube JPEG, PNG o WebP hasta 15 MB. Se convierten a WebP de hasta 1800 px y 5 MB. Para HEIC, exporta primero a JPEG.
  • Textos y marca: cambia nombre, textos, redes, logotipo y portada. Mantén los avisos de demostración mientras queden ejemplos ficticios.
  • Guardar borrador: conserva los cambios privados. Vista previa: muestra cómo quedarán antes de publicarlos.
  • Publicar: sustituye el contenido público por el borrador guardado. Los visitantes lo verán al recargar.
  • Para eliminar una fotografía usada, retírala del contenido, guarda y publica; después elimínala de la biblioteca.
  • «Descargar copia» respalda textos y referencias a imágenes; no descarga los archivos de imagen. Conserva tus fotografías originales.

Las fotos están en un bucket privado. Solo se firman enlaces temporales para imágenes publicadas o para tu sesión administradora. Una imagen ya publicada y descargada por un visitante no puede retirarse de sus dispositivos; los enlaces firmados emitidos pueden funcionar hasta una hora después de retirar la foto.

Comprobación final

Desde una ventana de incógnito, comprueba que se ve el catálogo y que un producto oculto no aparece. Edita un texto, guarda y confirma que aún no cambia en esa ventana; después publica y recarga para ver el resultado.

La web sigue siendo informativa. No incluye compras, reservas ni pedidos.
